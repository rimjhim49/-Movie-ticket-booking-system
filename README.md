MOVIE TICKET BOOKING SYSTEM

Compile:
g++ -std=c++17 main.cpp -o movie

Run:
./movie

This project follows the assignment requirement:
- One class per .cpp file
- No header files
- Menu-driven C++ console application
- Movie/show/seat booking
- Silver/Gold/Platinum pricing
- UPI/Card/Cash
- Ticket printing
- Cancellation
- OOP and SOLID concepts
